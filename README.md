# Flappy Chairman V2 — Clean Edition

A cleaner fork of the original Flappy Chairman project by Aether.

This version is focused on:

- a smaller and easier-to-edit UI
- only the default bird plus Mao, Xi Jinping, and Trump
- cleaner asset organization under `assets/`
- separate styles in `src/style.css`
- background music for gameplay and hit sound only on death
- fewer distractions and no leaderboard or extra menus

## Preview locally

```bash
cd /workspaces/Flappy-ChairmanV2
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000` in your browser.
