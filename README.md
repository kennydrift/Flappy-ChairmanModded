## 🚀 Quick Start

### Play Online
Simply open `index.html` in your browser and start playing!

### Local Development
```bash
# Clone the repository
git clone https://github.com/kennydrift/Flappy-ChairmanV2.git
cd Flappy-ChairmanV2

# Open in your favorite browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

**No build process required** — pure vanilla JavaScript!

## 🎮 How to Play

### Controls
- **SPACE** or **CLICK** to make the Chairman flap
- **ESC** to open/close the mod menu
- **P** to pause/resume the game

### Game Objective
Navigate through the pipes without hitting them. Each successfully passed pipe earns you points!
